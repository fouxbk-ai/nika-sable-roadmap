# Nika Sable Roadmap

Одностраничный Astro-сайт, который строит roadmap и диаграмму Ганта из заметок vault.

## Локальный запуск

```bash
cd site
pnpm install
pnpm dev
pnpm build
```

`pnpm dev` открывает сайт на `localhost:4321`. `pnpm build` собирает статический сайт в `site/dist`.

## Источник данных

Источник истины — только Markdown-файлы задач:

```text
30-Проект/задачи-для-кодекса/2026-*.md
```

JSON-манифесты и отдельная база не используются.

## Поддерживаемые поля frontmatter

```yaml
created: 2026-05-15
start: 2026-05-15
due: 2026-05-17
type: задача-для-кодекса
блок: 12
status: открыта
зависит-от: [блок-11]
```

- `created` — обязательная дата создания.
- `start` / `due` — опциональные ручные даты Ганта. Если их нет, сайт вычисляет даты по зависимостям.
- `блок` — номер блока.
- `status` — `открыта`, `в работе`, `выполнена`, `сделана`, `заморожена`.
- `зависит-от` — массив строк вида `блок-5`.

Вычисленные даты рисуются пунктиром. Ручные даты отображаются обычной полосой.

## Прогресс

Прогресс считается только по чек-боксам `- [ ]` и `- [x]` внутри заметок. Статус задачи не подменяет прогресс.
